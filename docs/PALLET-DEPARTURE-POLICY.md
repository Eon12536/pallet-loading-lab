# 낮은 팔레트 자동 반출 중단 · 2026-10-10

현재 정책은 `streamEngine.ts`의 `DEPARTURE_HEIGHT_RATIO = 0.96`입니다.
최대 높이 2200 mm이면 자동 반출 기준은 2112 mm입니다. 낮은 팔레트는 대기 시간, 6개 거절 기록, 컨베이어 포화, 입력 소진만으로 반출하지 않습니다. 단일·확장 공정에 동일하게 적용합니다.

롤러/서브 선두와 현재 집기 가능한 후속 박스를 최신 팔레트 버전에서 모두 검사한 경우에만 배치 불가 선두를 수동 처리 대기로 분리합니다. 예약·후속 공간 보류를 실제 배치 불가로 간주하지 않습니다. 낮은 팔레트는 유지하고 뒤의 입고 박스를 계속 검사합니다. 배치·경로의 기존 안전 제약은 바꾸지 않습니다.

공급분 처리가 끝났다면 남아 있는 낮은 팔레트를 그대로 보여주며 `공급분 처리 종료 · 낮은 팔레트 유지 · 자동 반출 없음`을 표시합니다. complete는 공급분 처리가 끝났다는 뜻이며 모든 박스의 적재 성공을 의미하지 않습니다. 수동 처리·불량 격리 수량은 별도 표시합니다.

## 실제 측정

`pallet-retained-load.json`: 기본 단일 프로필, seed 42, 혼합 240개, 1800 × 1500 × 2200 mm, 불량 이벤트 16%, 기존 실전 오차·도구·지지·하중 조건.

- 팔레트 유지: 75개, 높이 1661 mm
- 팔레트 반출: 0회
- 수동 처리 대기: 128개, 불량 격리: 37개
- 공급분 처리 완료, 모든 확정 배치의 기존 정적 제약 재검사 통과
- 계산 90.2초, 시뮬레이션 시간 5441초; 실제 로봇 측정 아님

목표 높이 2112 mm에 도달하지 못했으므로 반출하지 않았습니다. 이번 변경은 낮은 팔레트 유지 정책이며, 공간·지지·하중·경로 제약을 무시해서 목표 높이를 보장하는 알고리즘이 아닙니다. 새 팔레트 교체를 줄이면 수동 처리 대기가 늘 수 있습니다. 높이, 팔레트당 수량, 전체 처리율을 같은 성과로 취급하지 않습니다. 과거 `pallet-fill-policy.md`의 마지막 부분 팔레트 반출 규칙은 이번 정책으로 대체되며 과거 측정 결과는 재측정한 현재 결과가 아닙니다.
