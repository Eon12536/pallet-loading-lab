# 무작위 박스 반복시험 순위

기존 단일 팔레트 화면 `/?palletView=simple#pallet` 하단에 순위표를 추가했습니다. 기존 적재 알고리즘, 제약 검사, 팔레트/로봇 모델은 변경하지 않습니다.

## 공통 조건

- 로봇팔 1대, 팔레트 1개, 1200 × 1000 × 2200mm, 자동 반출 없음.
- 알고리즘: Future-Aware Hybrid, Greedy, 무작위 배치. 각각 100회, 총 300회.
- 시드 42~141. 각 시드의 박스 구성과 실제 입고 순서를 세 알고리즘이 공유합니다.
- 6종 박스: 가로 300~600mm/50mm, 세로 250~450mm/50mm, 높이 140~220mm/20mm의 균등 추출. 질량 2~10kg, 0.1kg 반올림. 120개 각각의 종류를 6종에서 균등 추출하고 입고 순서를 무작위로 섞습니다.
- 회전은 세운 상태 0/90도. 최소 지지율 95%, 로봇 가반하중 35kg, 박스 허용 상부하중 120kg은 합성 시험 가정값입니다. 실제 물성으로 표현하지 않습니다.
- 기존 탐색 설정, 판단 한도 10초/회, 전체 trial 한도 180초. 현재 박스와 잔여 종류별 수량만 계획기에 전달합니다. 실제 미래 입고 순서는 평가기에만 있습니다.
- 배치 불가 박스는 보류하고 후속 박스를 배치한 뒤 다시 검사합니다. 모든 남은 박스가 같은 상태에서 실패하면 종료하되 팔레트는 유지합니다.

## 평균 점수

기존 6축 식을 재사용합니다. 완료율 40%, 공간 밀도 20%, 최소 지지율 15%, 하중 균형 10%, 추정 작업 효율 10%, 실측 계산 속도 5%입니다. 원시 공간 활용률과 점수의 공간 밀도는 분모가 다릅니다.

- 완료율 = 적재 수 / 공급 수 × 100.
- 공간 밀도 = 적재 부피 / (팔레트 바닥 면적 × 실제 적재 높이) × 100.
- 최소 지지율 = 확정 박스 중 최저 바닥 접촉 비율 × 100.
- 하중 균형 = 100 × (1 − 기존 바닥 하중 불균형).
- 작업 효율 = 100 × clamp((40 − 추정 초/박스) / 35).
- 계산 속도 = 100 / (1 + 실측 P95 판단시간 / 100ms).

회차별 가중합 점수를 먼저 계산하고, 알고리즘별 표본 평균으로 정렬합니다. 완료된 유효 회차가 n개 미만이면 순위를 확정하지 않습니다. 오류/시간초과/제약 위반/미측정 축에 임의 0점이나 100점을 주지 않습니다. 정상적인 일부 미적재는 오류와 구분합니다.

표준편차는 점수 변동이며, 평균 95% CI는 기존 Student-t 근사입니다. 알고리즘 차이는 같은 시드끼리의 대응 차이를 집계합니다. 차이 CI가 0을 포함하면 우열이 명확하지 않습니다. 다중 비교 보정 없는 탐색적 결과입니다. 시드/물품 분포가 현장을 대표하지 않으면 반복 횟수를 늘려도 현장 성능을 보장하지 않습니다.

## 실행과 검증

화면에서 반복 n(10/30/50/100/500), 시작 시드를 선택하고 실행합니다. Worker로 계산하고 취소할 수 있습니다. 기존 3회 재생 비교와 반복시험은 동시에 시작하지 않습니다. JSON과 순위 CSV를 다운로드할 수 있습니다.

실측 실험은 독립된 25회 배치 4개를 동시에 실행합니다. 배치 안에서는 세 알고리즘을 순차 실행하고 회차별 알고리즘 실행 순서를 교대합니다. 각 배치의 알고리즘별 워밍업 1회는 점수에 포함하지 않습니다. 공유 기기의 동시/백그라운드 부하가 시간 지표에 영향을 줄 수 있으므로 독점 CPU 지연 측정으로 해석하지 않습니다. UI 재측정은 단일 Worker 순차 실행이며 계산시간 점수가 달라질 수 있습니다.

`pallet-random-ranking.test.ts`는 생성 재현성, 가중치, 미완료/실패 제외를 검사합니다. 실측 모드는 `RUN_RANDOM_RANKING=1`이며 `RANK_BATCH`, `RANK_FIRST`, `RANK_LAST`로 독립 배치를 지정합니다. `MERGE_RANDOM_RANKING=1`로 `pallet-random-ranking-merge.test.ts`를 실행하면 300개 결과의 ID·시드·입력 fingerprint·입고 순서·제약 위반·반출 여부를 검사해 합칩니다.

결과 파일: `simple-random-ranking.json`(설정, 물품 카탈로그, 시드, 버전, 원시 지표, 신뢰구간, 대응 차이), `simple-random-ranking.csv`(순위표). 이전 고정 4종/3시드 결과와 별도 보존합니다.

## 검증 범위

정적 지지/하중 및 직육면체 기하, TCP/그리퍼 경로 근사의 모델 성능 순위입니다. 실제 관절 IK, 진공/밀봉, 동적 붕괴, 실측 재료 강도는 미검증입니다. 6축 모델 점수가 이 검증 공백을 메우거나 실제 로봇 안전 인증을 뜻하지 않습니다.
