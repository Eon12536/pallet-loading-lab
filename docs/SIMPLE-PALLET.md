# 단일 팔레트 비교 화면

경로: `/?palletView=simple#pallet`. 기존 전체 화면은 변경하지 않고 별도 화면을 추가했습니다.

1200 × 1000 mm (기존 1800 × 1500 mm 가로·세로의 2/3), 로봇팔 1대, 팔레트 1개. 기본 120개, 높이 2200mm, 시드 42~44. 공급·남은 박스 후보 검사 완료 후에도 팔레트를 반출하지 않습니다.

기존 random, greedy, future-hybrid 및 runThreeTrial, BenchmarkController, PalletScene을 재사용합니다. 각 알고리즘은 같은 도착 순서·박스·물성·안전 제약으로 독립 실행됩니다. 미래 실제 순서는 계획기에 전달하지 않습니다. 판단 예산 10초, trial 180초, Worker 취소 지원. 정상적으로 보류된 박스는 후속 적재 후 재검사합니다.

`npm run dev`, 위 경로 열기 → 조건 지정 → 같은 조건으로 비교. 알고리즘 탭 → 재생/한 단계/완성 보기. 결과 JSON에 설정, 버전, 시드, 원시 지표 및 모든 판단 단계가 저장됩니다. 기존 테스트에 새 `tests/pallet-simple-study.test.ts` 추가.

## 실제 측정

3개 알고리즘 × 3개 시드, 미채점 워밍업 및 Greedy 재현성 확인. 두 테스트 통과 (107.28초). 최종 기하·정적 제약 위반 0, 팔레트 반출 0. TypeScript와 생산 빌드 통과.

|알고리즘|평균 적재 수|공간 활용률|높이 mm|평균 P95 ms|
|---|---:|---:|---:|---:|
|Future-Aware Hybrid|51.3|61.5%|1980|196.2|
|Greedy|26.7|31.8%|1980|63.1|
|무작위|32.3|36.5%|1980|29.9|

정확한 원시 수치는 simple-pallet-benchmark.json. 이 합성 입력에서의 결과이며 보편적인 알고리즘 우열은 아닙니다. 박스 허용 상부하중 120kg은 합성 가정값, 지지·하중은 정적 근사, 로봇 작업시간은 TCP 경로 추정입니다. 실제 IK/진공/동적 붕괴는 미검증입니다.
