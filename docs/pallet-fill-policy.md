# 조기 반출 및 고층 적재 개선 (2026-10-10)

## 변경
- 단일 시연은 작업 팔레트 한 장을 유지한다. 앞 박스 실패/30초 대기를 팔레트 포화로 간주하지 않는다.
- 롤러에 완전히 올라와 정지한 후속 박스를 검사한다. 정상적으로는 선두 우선이며, 선두가 배치/경로 불가이거나 상부 전용 박스가 적재를 막으면 안전한 후속 박스를 집는다.
- 최신 팔레트 버전에서 집기 가능한 정지 박스 전부를 거절했고 대기열이 막혔거나 입고 마지막 배치가 모두 실패한 경우에만 교체한다. 시간만으로 반출하지 않는다.
- 대기 박스와 그리퍼/운반 상자 사이의 연속 경로 교차를 검사한다. 측정된 대기 박스 상단을 넘도록 상승하되 기존 TCP 작업공간과 가상 로봇 도달 한계를 검사한다.
- 단일 혼합 시연의 기둥 높이/받침 폭 1.8 한계는 선호 점수로 변경한다. 누적 하중 합력의 무게중심 여유, 0.15g 수평 가속도 설계 가정, 최소 지지율 92%, 허용하중 안전계수 1.5, 경계, 충돌, 높이, 경로는 필수 제약으로 유지한다. 포장 규격 사용자 시나리오에는 이 프로필을 자동 적용하지 않는다.
- 기본 높이 2200mm(가로1800/세로1500보다 높음), 조절600–3000mm. 단일 기본 공급240개, 확장480개, 입력8–480개. 기존 strength/질량/치수는 임의 확대·축소하지 않는다.
